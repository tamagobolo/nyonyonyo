# RDR / ADR — 判断記録の記入例

重要な要求変更ならRDR、設計上の選択ならADRとして既存の記録場所に残す。両方を毎回作る必要はない。現行仕様・設計はそれぞれの本文を更新し、この記録と相互に参照する。

- 種別 / 識別子 / 日付 / 状態: （既存の命名に合わせる）
- 対応する現行仕様または設計: （実在するパス）
- 判断が必要になった状況: （事実と制約）
- 重視した基準: （正解・合格・危険のどの基準か、その理由）
- 採用した選択: （簡潔に記入）
- 検討した代替案と採用しなかった理由: （実際に検討したものだけ）
- 影響・検証方法・結果: （実行結果と未検証を分ける）
- 見直す条件 / 置き換える記録: （前提が変わる条件）

個人情報・秘密値・不要な会話全文を記録しない。
