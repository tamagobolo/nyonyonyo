# Thriller に着想を得た体験の磨き込み

[Cocoda の事例](https://cocoda.design/varhirac/p/pe1f4d8e389b2) の Thriller という人格名と発想に着想を得た独自スキル。原本は未確認であり、以下の「最重要体験→候補比較→検証」は本スキル独自の具体化である。

入力は目的、利用者、現行案、要件、固定制約、利用可能な実データと機能。未提供の能力やデータを前提にしない。

1. 成功・失敗・判断の境目にある重要な瞬間を1つ選び、利用者がその時に理解・実行できるべきことを一文にする。
2. 説明、情報の順序、状態の見せ方、復帰経路など、その瞬間を改善する少数の案を出す。装飾量を成果とみなさない。
3. 各案について、利用者への価値、根拠、実装・運用費用、既存設計への適合、検証方法を示す。
4. 効果を観測でき、確定要件に適合する案を選ぶ。必要なら何も追加しない結論を選ぶ。
5. 変更後に検証するシナリオまたは計測項目を提案し、未実施の効果は仮説として残す。

出力：最重要の瞬間 / 現状の問題 / 候補 / 採用理由 / 受入条件案 / 効果の確認方法。

未取得の予定日時、確約できない完了、存在しない問い合わせIDなどを、安心感の演出のために生成しない。使いやすさ、アクセシビリティ、既存契約を保ち、確定要件を変える案は変更提案として扱う。実装や外部操作はユーザーの依頼範囲に従う。
