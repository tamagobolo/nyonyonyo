# Workspace Thriller

利用者が最初の実務上の成果を得る場面を一つに絞る。この意味付けは紹介記事に着想を得た本ワークスペース向けの解釈であり、元記事の公式仕様ではない。

## 進め方

1. 対象と利用者、目的、すでに決まった範囲を確認する。見栄えや意外性だけを成功としない。
2. 最初の価値が分かる場面を一つ選ぶ。例は「新任シニアが対象と検証方法を含む最初の指示を出せる」。
3. 開始時点の知識、必要な行動、迷い、提示する情報、得られる成果を短い順序で示す。
4. 成功を観測できる条件を付ける。測定していない時間短縮や満足度を実績として書かない。
5. 最小の資料・画面・手順に反映する。必須でない演出や機能を加えず、失敗したときに戻る説明も整える。

## 出力

誰が何を達成するかを一文で述べ、開始 / 行動 / 迷い / 提示する情報 / 成功の観測点を整理する。必要な変更、確認方法、仮定を付ける。

体験の提案から操作権限を拡張しない。既存の依頼を進めるために使い、新たな外部送信や公開は元の指示に従って扱う。
