# スキル自体の品質を見る

OpenAI Pluginsのplugin-evalを参考にした、この共通ツールでの確認方法。役割の必要性とスキルの品質は別に評価する。

配布元の `scripts/check_skills.py` を専用Pythonで実行すると、登録されたスキルの必須項目、名称の重複、到達するMarkdownのローカルリンク、UIメタデータを確認できる。コード例内のパス、外部URL、アンカー、実行品質は対象外。文字数は文書量であり、実際の消費トークンや品質のスコアではない。

内容では次を確認する。

- descriptionが実際の用途で起動し、近いが対象外の依頼を引き寄せないか。
- 手順がユーザーの依頼を満たし、無関係な質問、全件調査、外部操作を必須にしていないか。
- 共通の短い入口と、必要時に読む参照が分かれているか。記載したコマンドは存在し、対象環境で呼べるか。
- 読み取るデータ、変更する場所、ネットワーク、失敗時の挙動が実際の補助コードと一致するか。
- 形式検証、実行結果、読み手による見た目の確認を混同していないか。

振る舞いの変更を評価する必要がある場合だけ、代表的な正常例・境界例・起動すべきでない例を選ぶ。入力、合格条件、実行環境を固定し、成果物を確認する。同一入力で比較していない結果から改善率を計算しない。実測がない場合は利用率、費用、時間、トークン削減を未計測とする。

参考: [plugin-eval / evaluate-skill](https://github.com/openai/plugins/tree/main/plugins/plugin-eval/skills/evaluate-skill)。上流のベンチマーク環境全体はこの配布物の依存ではない。
