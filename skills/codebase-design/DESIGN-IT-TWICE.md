# 代替案を比較する

ユーザーが複数案を求める場合や、変更しにくい公開契約に大きいトレードオフがある場合に使う。

現在の呼出例、不変条件、入出力、エラー、依存、互換性を短く記載する。[依存と検証](DEEPENING.md) を参考に、候補間で守る条件をそろえる。

最小の公開面、代表的な呼出側の使いやすさ、外部I/Oの分離など、実際の判断軸に沿って少数の案を作る。根拠のない汎用性を競わせない。独立した発想が役立ち、親が別の有用な作業を進められる場合は、範囲と成果物を決めて子へ委譲できる。固定人数の並列起動は不要。

各案は公開契約、短い使用例、内部に隠す責務、検証方法、移行の影響を示す。比較では隠せる複雑さ、変更の局所性、呼出側の負担、移行コストを説明し、一案を推奨する。すでに実装を承認された範囲では、その判断を引き継いで進める。
