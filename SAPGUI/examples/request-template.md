# 生成依頼テンプレート

分かる範囲で埋める。認証情報は書かない。録画を共有する前に、入力済みの個人情報・業務値を架空値に置き換える。実際の録画と生成物は `local/` と `output/` に保管する。

```text
$sap-gui-scripting を使ってスクリプトを生成してください。

目的:
SAP GUIの種類と版:
希望する言語: VBScript / VBA / Python
対象: 開発 / 検証 / 本番
対象セッションの識別条件（システムID・クライアント等）:
開始トランザクションと開始画面:
操作手順:
入力形式と件数:
期待する結果・ファイル形式・保存先:
保存・転記・削除・送信などの更新操作:
同じ入力を再実行した場合の扱い:
提供できる録画・画面ID・既存コード:
今回の範囲: ファイル生成まで / 指定した検証環境で実行まで
生成先: output/
```

依頼例:

```text
SAP GUI for Windows 8.00で、既に開いている照会画面のALVから
指定列をCSVに保存するVBScriptを作成してください。
録画とALVの列キーは local/recording.vbs にあります。
複数セッションがあるため、検証用システム・クライアント・ユーザーを
引数で照合し、一致する対象を確定できない場合は停止してください。
出力は output/export.vbs。今回は生成までです。
```

録画なしの依頼例:

```text
受注照会を自動化したいです。まだ録画はありません。
公式APIで作成できる接続部分を用意し、業務部分に必要な録画区間を示してください。
不明な画面IDは仮定せず、業務処理が未完成の状態では実行が止まるようにしてください。
```
