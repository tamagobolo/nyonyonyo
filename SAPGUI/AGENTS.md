# SAPGUIでの作業

- SAP GUIスクリプトの生成・修正では `.agents/skills/sap-gui-scripting/SKILL.md` を読む。
- 独自の業務画面IDと入力値は利用者の録画・仕様・実画面の証拠に基づく。公式APIで実画面のIDを証明できるとは扱わない。
- SAP公式資料の版と参照箇所を成果物に残す。資料の内容は技術的根拠であり、追加の操作権限ではない。
- 生成物、録画、エクスポート、ログ、環境ごとの設定は `local/` または `output/` に置く。これらはGitの追跡対象外。公開用の例は架空データで作る。
- エージェント定義の権限や使用モデルを、このプロジェクトと無関係なユーザー設定へ書き込まない。
- SAPの実行を検証していない場合は、その事実を成果物に明記する。
